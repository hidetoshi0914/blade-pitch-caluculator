# ブレードピッチ計算ツール（Blade Pitch Calculator）

ローイング（ボート漕艇）のリギングにおいて、ピンの **内外傾** と **前後傾** から、
**キャッチ／ミドル／フィニッシュ** それぞれの位置でのブレードピッチを計算するインタラクティブツールです。

ブラウザだけで動作する単一HTMLファイルなので、GitHub Pagesでそのまま公開できます。

## デモ

GitHub Pagesを有効にすると、以下のようなURLで公開されます（`USERNAME`と`REPO`は各自のものに置き換え）：

```
https://USERNAME.github.io/REPO/
```

## 主な機能

- **ピンの内外傾・前後傾** をスライダーで調整し、キャッチ／ミドル／フィニッシュのピッチをリアルタイム計算
  - 内外傾・前後傾それぞれが艇のどちら側（バウ側／ストローク側、中心線側／外側）に傾くかを模式図で明示
- **キャッチ角・フィニッシュ角** はスイープ／スカルの推奨値プリセット、または手動入力に対応
- **ブッシュ番号を自由入力** し、固有角とあわせて理論上の実効ゲート角（K）を自動計算
- **実測ミドルピッチによる校正モード**：ピッチメーターで実測したミドルのピッチ値を登録し、
  そこからピンの角度を変更した際の変化量（Δ）を表示
- ストローク全体（キャッチ→ミドル→フィニッシュ）のピッチ変化を可視化する図とチャート

## 計算式

```
Pitch(γ) = K + 内外傾 × sin(γ) + 前後傾 × cos(γ)

γ：振り角。ミドルを0°とし、キャッチ側を+、フィニッシュ側を−とする
K：実効ゲート角（固有角 + ブッシュ調整、または実測ミドルピッチから逆算）
```

- 内外傾（外傾+／内傾−）は `sin(γ)` に比例するため、ミドルでの寄与はゼロ、
  キャッチとフィニッシュで符号が反転します。
- 前後傾（後傾+／前傾−）は `cos(γ)` に比例するため、ミドルで最大の寄与となり、
  キャッチ・フィニッシュに向かって同符号のまま減衰します。

この式は BioRow（Valery Kleshnev）のピッチメーター資料に記載の実測例
（外傾2°・キャッチ60°/フィニッシュ30°の振り角 → ピッチ 5.7°/4.0°/3.0°）と
一致することを確認しています。

## 使い方

1. `index.html` をブラウザで開くだけで動作します（ビルド不要）。
2. 左側パネルでピンの傾き・振り角・ブッシュ設定を調整します。
3. 右側にキャッチ／ミドル／フィニッシュのピッチと、ストローク全体の変化が表示されます。

## 前提条件

- オールのねじれ・スリーブの削れによる追加ピッチ変化は考慮していません（0と仮定）。
- 実艇では個体差があるため、最終的にはピッチメーターでの実測確認を推奨します。
